Two headings in one file carry the same section number.
- Renumber the heading that breaks the sequence to the number that fits between its neighbors,
  and update the `§` references (in every file) that mean the renumbered section.
- Change only the number in the heading, never its title.
- If you cannot tell which references mean which section, renumber the heading, leave those
  references as they are, and list them in `questions`.
