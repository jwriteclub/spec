`#N.N` text that would match a numbered section if written `§N.N`.
- If the sentence refers to the section, write the `§` form; when several files have that number,
  the qualified form `§stem:N.N` of the one meant.
- If `#N` is an issue, pull request or list number, propose no edit and say so in `summary`.
