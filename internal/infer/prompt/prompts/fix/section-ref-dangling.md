A `§N` reference that matches no numbered section.
- If the section was renumbered or the number has a typo, point the reference at the section the
  sentence means (compare its wording with the section titles in the files). If it means a section
  of another file, write the qualified form `§stem:N`.
- Never renumber sections to make a reference resolve, and do not change the sentence otherwise.
- If no section fits, propose no edit and ask in `questions` which section was meant.
