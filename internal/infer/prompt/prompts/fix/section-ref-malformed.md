A `§` section reference followed by letters or digits (`§5.2ab`, `§5.2for`), so it is not read as a
reference. A section number is digits and dots with at most one trailing lowercase letter.
- If a space is missing ("§5.2for" -> "§5.2 for"), insert it.
- If the number has a typo, write the number of the section the sentence means.
- Change nothing else in the sentence.
