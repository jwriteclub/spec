A name defined more than once.
- If the definitions mean the same thing, keep one (the more complete, or the one in the file where
  the concept belongs) and delete the other. A sentence that only the deleted one has moves into the
  kept one, word for word.
- If they mean different things, rename one of them to a new name in the same family and update the
  references that mean the renamed one. Every reference must still point at what it meant.
- A paragraph that starts with a bold `**$Name**` reference is read as a label and defines the name
  again; if that is the cause, start the sentence another way or drop the bold.
- Ask in `questions` when a reference could mean either definition.
